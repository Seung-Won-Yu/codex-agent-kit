알아서 움직여도
선을 넘지는 않습니다.

이전 승인은 같은 대상·행위·목적에만 이어받습니다. 개인 설정 변경을 저장소 수정이나 게시로 확대하지 않고, “원인만 / 수정하지 마” 같은 새 제한도 지킵니다.

많이 부르지 않고
정확히 연결합니다.

담당 스킬은 확정된 목적과 완료 기준을 이어받습니다. 단계마다 다른 스킬을 읽지 않고 필요한 빈칸만 보충하며, 문서 형식도 실제 사용 목적에 맞춰 선택합니다.

만들었다가 아니라
확인했다로 끝냅니다.

변경된 동작부터 검증하고 문제가 있으면 범위를 넓힙니다. 고정 화면 크기 검사나 단계별 전체 빌드를 강제하지 않으며, 커밋은 승인된 범위에서 수행합니다. 6개 사례의 전후 비교에서 완료 품질은 유지됐으며, 토큰 절감은 입증되지 않았습니다. 비교 결과 보기 ↗

10 Connected Plugins

스킬에서 실제 작업까지
끊김 없이

문서, 브라우저, 데스크톱과 배포 도구를 필요한 순간에만 연결합니다.

DOC

Documents

Word·DOCX 문서를 생성, 편집, redline하고 렌더링까지 검증합니다.

XLS

Spreadsheets

XLSX·CSV 분석과 workbook 생성을 담당합니다.

PPT

Presentations

PowerPoint·Google Slides용 발표 자료를 만들고 편집합니다.

PDF

PDF

PDF를 읽고 생성하며 페이지 렌더링으로 레이아웃을 확인합니다.

TPL

Template Creator

기존 문서를 재사용 가능한 Codex artifact template로 변환합니다.

WEB

Sites

웹사이트 source, version, production deployment와 access control을 관리합니다.

BRS

Browser

Codex 안의 독립 브라우저로 페이지 탐색, 입력과 화면 검증을 수행합니다.

CHR

Chrome

로그인 상태와 기존 탭이 필요한 작업을 사용자의 Chrome에서 처리합니다.

CUA

Unified Computer Use

연결된 브라우저 UI를 탐색하고 조작합니다. 지원 범위는 실행 환경에 따라 달라집니다.

VIZ

Visualize

차트, 비교 도구, 시뮬레이터와 interactive visualization을 대화 안에서 만듭니다.
