## 재현

[평가 스크립트](../../scripts/eval-skill-efficiency.py)에 요청과 초기 파일이 들어 있습니다. 별도 checkout의 기준 `skills` 폴더와 새로운 임시 출력 폴더를 지정합니다. `--run`이 있어야 12개 계정 기반 모델 실행을 시작합니다.

```bash
python3 scripts/eval-skill-efficiency.py --run \
  --before-skills /path/to/baseline-checkout/skills \
  --output /tmp/codex-skill-eval-new \
  --codex /path/to/codex
```

재현 스크립트는 모든 사례를 독립 Git root로 만들고, 종료 오류·시간 초과·빈 답변·완료 이벤트 누락 시 nonzero로 종료합니다. 측정 당시에도 모든 출력 폴더는 다른 Git 저장소 밖의 임시 경로였습니다.

후속으로 특정 스킬만 바뀌었다면 `--ids E01`처럼 관련 사례만 실행할 수 있습니다.

결과의 `answer.md`, 변경 파일, `trace.jsonl`, `metrics.json`을 함께 확인해야 합니다. 프로세스 종료 성공은 결과 품질의 자동 합격 판정이 아닙니다. 저장소 변경마다 이 비교를 자동 반복하지 않고, 의미 있는 스킬 변경이나 실제 재작업 사례가 생겼을 때 해당 행동을 확인하는 데 사용합니다.
